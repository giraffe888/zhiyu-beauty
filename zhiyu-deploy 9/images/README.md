# 知予 · 项目配图说明

## 当前配图

19 张 **产品/器械元素插画**（SVG 矢量，640×240 横向），由平台自制，**无版权风险**：
- **注射类**：注射器、药瓶、分子结构、微球、DNA 螺旋等
- **光电类**：激光束、射频波、微针阵列、光波形等
- **皮肤管理**：皮肤层、液滴、剥落效果等
- **手术类**：眼部/鼻部轮廓线条

## 为什么不用真人照片

⚠️ **医美行业使用真人照片有合规风险**：中国医疗广告法规禁止利用患者形象作证明，
术前术后对比图更是敏感区。使用产品/器械元素既能清晰传达项目属性，又规避了合规风险。

## 如何替换为其他图片

在后台编辑项目时，「配图」字段支持两种方式：

| 方式 | 填写示例 | 适用场景 |
|------|---------|---------|
| 本地文件名 | `botox.svg` | 使用平台自带配图 |
| 站内路径 | `/images/custom/botox.png` | 自己上传到部署目录 |
| 外部 URL | `https://example.com/img.jpg` | 使用免费图库或 CDN 图片 |

⚠️ **使用图库照片时注意**：
1. 避免使用**可识别的真人面部**（尤其医美场景），以防肖像权与广告合规风险
2. 优先选择**产品、器械、实验室、抽象质感**类图片
3. 保留图片来源与授权说明，便于后续核查
4. 即使图库授权商用，也不代表可规避医美广告法规对"效果展示"的限制
